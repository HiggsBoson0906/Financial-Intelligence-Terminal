# Frontend-Backend Contract

## Purpose
This document outlines how the frontend and backend interact, ensuring parallel development can proceed smoothly based on shared API contracts.

## Agreement
1. **Source of Truth:** The OpenAPI schema (`/openapi.json` and `/docs`) generated by FastAPI is the ultimate source of truth for request and response structures.
2. **Implementation Status:** Endpoints not yet implemented will return `501 Not Implemented`. The frontend should handle these gracefully during the development phase.
3. **Types:** The frontend team should generate or manually mirror TypeScript interfaces corresponding to the Pydantic schemas defined in the backend.
4. **Error Handling:** The frontend must parse the standard `{"error": {"code": "...", "message": "..."}}` response format and display appropriate feedback to the user.
5. **Separation of Concerns:** The frontend focuses solely on presentation and user interaction. All heavy lifting, data retrieval, multi-agent orchestration, and quantitative calculations remain on the backend.
